# Contributing to OpenBook AI

We welcome contributions from the community! OpenBook AI is dedicated to remaining 100% open-source, client-side, and free forever.

## How to Contribute

1. Fork the repository on GitHub.
2. Create a new topic branch (`git checkout -b feature/my-new-feature`).
3. Commit your changes (`git commit -am 'Add new feature'`).
4. Push to the branch (`git push origin feature/my-new-feature`).
5. Open a Pull Request.

## Coding Guidelines

- Use TypeScript strictly.
- Ensure all file parsing and operations remain client-side (no backend dependencies).
- Format code using Prettier and check TypeScript build with `pnpm run build`.
